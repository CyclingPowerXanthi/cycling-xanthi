Cycling Power Xanthi
Cycling Power Xanthi
Παρουσίαση project

Είμαστε οι Cycling Power Xanthi από την Ξάνθη, μια ομάδα παιδιών που αγαπάμε τις ανοικτές τεχνολογίες και πιστεύουμε ότι η τεχνολογία μπορεί να κάνει την καθημερινότητα μας καλύτερη. 
Με αφορμή ένα σοβαρό ατύχημα που είχε ένα παιδί της ομάδας μας με το ποδήλατό του, σκεφτήκαμε να χρησιμοποιήσουμε την τεχνολογία για να προτείνουμε ένα ασφαλές ποδήλατο το οποίο θα προστατεύει τον αναβάτη. Το ποδήλατό μας θα διαθέτει αισθητήρες που θα: φρενάρει όταν ανιχνεύσει εμπόδιο, θα περιορίζει την ταχύτητα όταν αυτή είναι μεγάλη, θα έχει ένδειξη αν ο αναβάτης δεν φορέσει κράνος, θα ανιχνεύει πτώσεις και θα εκπέμπει σήματα (ηχητικό και οπτικό), θα ανιχνεύει την κίνηση γύρο από τ ο ποδήλατο, θα ανάβει αυτόματα φώτα αν είναι νύχτα και πολλά άλλα.
Μελλοντικά θα θέλαμε να προτείνουμε την υιοθέτηση του κιτ ασφαλείας που θα φτιάξουμε στον δήμο Ξάνθης στον οποίο θα προτείνουμε να υπάρχουν ασφαλή ποδήλατα σε διάφορα μέρη της πόλης μας της Ξάνθης τα οποία θα μπορούν να νοικιάζουν οι πολίτες για τις καθημερινές τους μετακινήσεις. 
Θα παρουσιάσουμε το project μας τόσο με μακέτα σε κλίμακα όσο και σε πραγματικό ποδήλατο. 

Εξοπλισμός που θα χρειαστούμε
•	Πλακέτα MicroBit (X3)
•	Αισθητήρες Διάφορους (συνολικά θα χρειαστούμε 15 αισθητήρες)
•	Αναλώσιμα MicroBit
•	Αναλώσιμα μακέτας και 3D printer
•	Σετ ρομποτικής mikrobit
